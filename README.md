# California Housing Price Prediction 🏡

An end-to-end machine learning project exploring the California Housing dataset to predict median home values. 

## 🛠️ Tech Stack
* **Language:** Python
* **Platform:** Google Colab
* **Libraries:** Pandas, Scikit-Learn, XGBoost, Matplotlib, Seaborn

## 📊 Workflow & Features
1. **Exploratory Data Analysis (EDA):** Inspected data distributions and generated correlation heatmaps.
2. **Preprocessing & Pipelines:** Utilized standard scaling and reproducible train-test splits (`random_state=42`).
3. **Model Training & Tuning:** Compared Linear Regression, Tuned Random Forest, and Tuned XGBoost using `GridSearchCV` and cross-validation.
4. **Evaluation & Testing:** Evaluated models using RMSE and $R^2$ scores, concluding with real-world sample house predictions.
